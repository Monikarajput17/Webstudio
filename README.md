# Monika Web Studio Portfolio

A premium multi-page freelance web designer/developer portfolio for local business clients.

Open `index.html` in a browser to view the site.

Main pages:
- `index.html`
- `demos.html`
- `services.html`
- `pricing.html`
- `process.html`
- `contact.html`
- `thank-you.html`

Demo pages:
- `restaurant.html`
- `school.html`
- `coaching.html`
- `clinic.html`
- `salon.html`
- `gym.html`
- `yoga.html`
- `business.html`
- `portfolio.html`

It is built as a static site with responsive HTML, CSS and JavaScript, so it can be deployed to Netlify, Vercel, GitHub Pages or any static hosting provider.
